## Entry

> The office coffee machine has two settings: broken, and broken but louder.

## Run

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads `entry.txt` and writes the entry text to `output.txt` in the directory given by `MAKEFUN_BOT_DIR` / `MAKEFUN_OUTPUT_DIR`.
